# WindowFinder — 윈도우 탐색기 스타일의 macOS 파일 탐색기

HTML/CSS/JS + Node.js(의존성 0개)로 만든, 윈도우 11 탐색기 UX를 그대로 옮긴 macOS용 파일 탐색기입니다.
브라우저에서 실행되지만 로컬 서버를 통해 **실제 Mac 파일시스템**을 탐색하고 조작합니다.

## 실행

```bash
node server.js          # 기본 포트 8890
# 또는 Finder에서 WindowFinder.command 더블클릭
```

브라우저에서 <http://127.0.0.1:8890> 접속. (127.0.0.1에만 바인딩 — 외부 접근 불가)

설치된 앱을 한 번 실행하면 쓰기 가능한 `/opt/homebrew/bin` 또는 `/usr/local/bin`에
`windowfinder` 명령을 자동으로 만듭니다. 터미널에서 현재 폴더나 지정한 폴더를 열 수 있습니다.

```bash
windowfinder               # 현재 폴더
windowfinder ~/Downloads   # 지정한 폴더
```

## 앱으로 빌드 (WindowFinder.app / .dmg)

```bash
./build.sh
```

- Node SEA(Single Executable Application)로 서버+UI를 **단일 실행파일**로 만들고,
  Swift로 컴파일한 **네이티브 WKWebView 셸**([native/main.swift](native/main.swift))을 앱 실행 파일로 하는
  `dist/WindowFinder.app`과 `dist/WindowFinder.dmg`를 생성합니다.
- 만들어진 앱은 **Node·Chrome 설치 없이** VS Code처럼 자체 창으로 뜹니다. 셸이 내장 서버를 자동 실행하고,
  **Finder에서 창으로 파일을 끌어다 놓으면 네이티브 경로로 실제 복사**됩니다(브라우저 업로드/다운로드 동작 없음).
- 빌드에는 Homebrew node가 아닌 공식 node 바이너리가 필요해 첫 빌드 시 1회 다운로드합니다
  (`~/.cache/windowfinder`에 캐시).
- DMG만 다시 만들려면 `./make-dmg.sh` (앱 빌드 후). 배포용 ZIP은 `dist/WindowFinder-<버전>.zip`입니다.

## GitHub 배포 + 자동 업데이트

앱에 자동 업데이터가 내장되어 있습니다. 실행 5초 후와 4시간마다 배포 위치의
`latest.json`을 확인하고, 새 버전이면 자동으로 내려받아 앱을 교체하고 재실행합니다.
(메뉴 > 업데이트 확인… 으로 수동 확인하면 적용 여부를 묻습니다.)

**배포 (GitHub Releases)**:

```bash
./deploy.sh           # 패치 버전 자동 증가 (1.0.0 → 1.0.1) + 빌드 + 배포
./deploy.sh 1.2.0     # 버전 지정 배포
```

구조 — 소스와 다운로드 채널 분리:
- 소스: `wedobby/WindowFinder`
- 다운로드(공개): GitHub Releases의 버전별 ZIP + 저장소의 `latest.json`
  → 설치된 앱은 `latest.json`의 주소만 바라보므로 소스 코드 구조가 바뀌어도 업데이트가 유지됩니다.

기능 변경을 커밋하고 테스트를 통과시킨 뒤 실행합니다. `gh` 설치·인증과 원격 푸시 권한이 필요합니다.

1. clean `main`, 도구·인증, 증가한 버전과 중복 태그 여부 확인
2. 버전 커밋 → 앱 빌드 → `WindowFinder-<버전>.zip` 생성
3. 빌드 후 소스가 동일한지 확인 → 같은 커밋에 태그 → main·태그 원자적 푸시
4. GitHub Release에 ZIP 업로드 → `latest.json` 갱신·커밋·푸시

설정 파일(로컬, git 제외): `update-url.txt`가 있으면 업데이트 주소를 덮어쓸 수 있습니다.

- **처음 설치** (팀원 안내용 — 터미널 한 줄, 격리 해제까지 자동):

  ```bash
  curl -fsSL https://raw.githubusercontent.com/wedobby/WindowFinder/main/install.sh | zsh
  ```
- 업데이트 시 격리 속성 제거·서버 재시작·앱 재실행까지 자동 처리됩니다

## 기능

**탐색**
- **폴더 변경 자동 감지**: 현재 폴더에 파일이 추가/삭제/변경되면 자동으로 새로 고침
  (0.8초 단위로 묶어서, 이름 편집·드래그 중에는 미룸)
- 뒤로/앞으로/상위 이동, 히스토리, 브레드크럼 주소창 (클릭하면 경로 직접 입력, `~` 지원)
- 사이드바: 즐겨찾기(홈·데스크탑·문서·다운로드 등), 폴더 트리, 마운트된 볼륨
- 딥링크: `#/경로` 해시로 특정 폴더 바로 열기
- 하위 폴더 전체 재귀 **검색** (Enter로 실행)

**보기**
- 자세히(정렬 가능한 컬럼) / 큰 아이콘 / 보통 아이콘 / 목록
- **macOS 네이티브 아이콘** (NSWorkspace 기반 — Finder와 동일한 앱/파일/폴더 아이콘)
- **Finder식 현지화 이름**: 시스템 언어 기준으로 앱·폴더 이름 표시 (계산기, 메모, 유틸리티, 데스크탑…) — 정렬도 표시 이름 기준
- `.app` 확장자 숨김 (Finder와 동일), 우클릭 → **패키지 내용 보기**
- **응용 프로그램 통합 뷰**: /Applications에 시스템 앱(/System/Applications)을 Finder처럼 합쳐서 표시
- 숨긴 항목 표시와 **시스템 파일 표시(.DS_Store, .localized, .Spotlight-V100 등)** 를 별도 토글로 분리
- 이미지 썸네일 (Quick Look 기반, 지연 로딩)
- 이름/날짜/유형/크기 정렬, 숨김 파일 표시 토글
- 미리 보기 창: 이미지·동영상·오디오·PDF·텍스트/코드
- 라이트/다크 모드 자동 (시스템 설정 따름)
- 설정(보기 방식·정렬·미리보기)은 localStorage에 저장

**Git / SVN**
- 폴더가 Git/SVN 작업 사본이면 명령 바에 **Git / SVN 버튼**이 자동 표시, 우클릭 컨텍스트 메뉴(파일·빈 공간)에도 주요 명령 노출
- 파일 목록에 상태 배지: `M` 수정, `A` 스테이지/추가, `U` 추적 안 됨, `D` 삭제, `C` 충돌, `R` 이름 변경 (변경이 있는 폴더에도 표시)
- **커밋 창에 커밋 대상 목록 표시** (SVN은 추적 안 된 파일이 제외 목록으로 구분됨)
- **Git Stage / Unstage**: Git 메뉴와 상태·커밋 창에서 Unstaged/Staged 목록을 나눠 표시하고,
  파일별·선택 항목·전체 Stage/Unstage 지원. 파일·폴더 우클릭으로도 바로 실행할 수 있습니다.
- **Git / SVN 변경 작업창**: 왼쪽에서 변경 파일을 검색·선택하고 오른쪽에서 줄 번호와 추가/삭제 색상이 있는 diff를 확인합니다.
  Git의 Unstaged/Staged diff를 각각 볼 수 있으며, SVN은 변경 사항/추적 안 됨 탭에서 추가·되돌리기·선택 커밋을 수행합니다.
  바이너리 파일은 안내를 표시하고 큰 diff는 앞 256KiB로 제한합니다.
- **커밋 작성**: 여러 줄 메시지, 같은 창에서 초안 유지, ⌘/Ctrl+Enter 커밋, 창 활성화·수동 새로고침을 지원합니다.
  Git은 커밋 직전 Stage 내용과 브랜치 변경 여부를 다시 확인하고, SVN은 선택한 항목만 커밋합니다.
- **Git 커밋은 Stage한 내용만 포함**: Stage 이후 추가 수정한 내용은 작업 폴더에 남습니다.
  Unstage는 파일 내용을 유지하며, 최초 커밋 전 저장소·삭제·이름 변경 파일도 지원합니다.
- 상태 표시줄에 현재 브랜치 표시
- **Git 그래프 뷰** (Fork/JetBrains 스타일): 왼쪽에 **브랜치/원격/태그 트리**(`/` 계층으로 폴더 접기, 현재 브랜치 경로 자동 펼침), 오른쪽에 컬러 레인 그래프 + 브랜치·태그 배지 + 작성자/해시/상대시간 컬럼
- 트리 항목·그래프 배지 클릭으로 **브랜치 전환(checkout)** — 원격 브랜치는 자동 추적 브랜치 생성, 태그는 detached HEAD 안내 후 체크아웃
- **상태바 브랜치 표시 클릭** → Git 그래프(또는 SVN 로그) 팝업
- **SVN 로그 그리드**: 리비전/메시지/변경 수/작성자/날짜 컬럼, 현재 리비전 하이라이트, **‘이동’ 버튼으로 특정 리비전으로 update**
- SVN 로그에서 리비전을 클릭하면 **하단 상세 패널**에 변경된 파일 목록(수정/추가/삭제 배지) 표시
- **무한 스크롤**: 목록 끝까지 내리면 다음 100개 자동 로드 / **기간 필터**: 시작~끝 날짜 지정 시 해당 기간 로그 전체 조회
- Git 그래프는 커밋 행을 클릭하면 변경 파일 목록이 행 아래로 펼쳐짐
- Git/SVN **상태 보기**도 배지 달린 목록 뷰로 표시
- **실시간 진행 창**: 커밋·풀·푸시·업데이트·클론·체크아웃·되돌리기 실행 시 결과 팝업 대신
  받는 파일 목록 스트리밍 + 진행률 바 + 전송 속도 + 경과 시간 + 취소 버튼이 표시됨
  (취소는 서버 작업 종료를 요청하며, 이미 반영된 변경을 자동으로 복원하지 않습니다.)
- **Git 클론 / SVN 체크아웃**: '새로 만들기' 메뉴 또는 빈 공간 우클릭에서 URL 입력으로 현재 폴더에 복제
- Git: 풀 / 푸시 / 페치 / 커밋 / 변경 요약, 우클릭으로 Stage·Unstage·변경 취소
- SVN: 업데이트 / 커밋 / **전체 되돌리기(변경 목록 확인 후 재귀 revert)** / 상태 / 로그, 우클릭으로 추가·되돌리기(-R 재귀) (svn CLI 설치 시)

**볼륨**
- 사이드바 볼륨에 호버하면 **⏏ 추출 버튼** 표시 (DMG 마운트·외장 디스크 마운트 해제), 우클릭 메뉴에도 있음
- 추출은 Finder → hdiutil → diskutil 순으로 시도, 볼륨이 사용 중이면 **강제 추출** 확인 창 표시
- 추출한 볼륨을 보고 있었다면 자동으로 홈으로 이동

**Finder 연동 (클립보드 · 드래그 앤 드롭)**
- Finder의 파일·폴더·빈 공간·사이드바 우클릭 메뉴에서 **“WindowFinder로 열기”**
  (Finder Sync 확장; `install.sh` 설치 시 자동 활성화. 직접 DMG로 설치했다면
  시스템 설정 → 일반 → 로그인 항목 및 확장 프로그램 → Finder 확장에서 한 번 활성화)
- 앱에서 ⌘C/⌘X → **Finder에서 ⌘V로 붙여넣기 가능** (macOS 시스템 클립보드에 실제 파일 참조를 올림)
- Finder에서 ⌘C → **앱에서 ⌘V로 붙여넣기 가능** — 탐색기 창끼리의 복사/이동도 같은 방식으로 동작
- 잘라내기(⌘X) 상태는 서버가 기억해 다른 창에서 붙여도 이동으로 처리
- **Finder → 앱 드래그 앤 드롭**: 파일·폴더(하위 구조 유지)를 떨어뜨리면 현재 폴더(또는 겨눈 폴더)로 복사
- **앱 → Finder 드래그 아웃**: 네이티브 앱에서는 파일·폴더·다중 선택 모두 Finder/데스크탑/다른 앱으로
  끌어다 놓으면 실제 복사됨 (파일 프라미스 방식). 같은 이름이 있으면 **덮어쓰기/둘 다 유지/건너뛰기** 확인 창
  (여러 개일 땐 ‘나머지에도 적용’). 브라우저 모드에서는 Chrome 한정 파일 1개.
- **탐색기 창끼리 드래그**: 같은 창 안 = 이동, 다른 창으로 = 복사 (⌥ 누르면 반대 동작)
- Git 저장소 폴더에서는 우클릭 → **Fork로 열기** (Fork 설치 시)

**연동**
- **VS Code로 열기** (파일·폴더·사이드바 어디서든 우클릭)
- Finder에서 보기, 터미널에서 열기
- **즐겨찾기 등록**: 폴더 우클릭 → 즐겨찾기에 추가 (사이드바 ★ 항목, 우클릭으로 제거)
- 사이드바(즐겨찾기·트리·볼륨) 전체 우클릭 컨텍스트 메뉴 지원

**파일 조작**
- 복사/잘라내기/붙여넣기, 이름 바꾸기(인라인, F2), 새 폴더/새 텍스트 문서
- 삭제는 **휴지통으로 이동** (Finder 경유 — 복원 가능)
- 드래그 앤 드롭 이동 (⌥ 누르면 복사) — 폴더·사이드바·브레드크럼에 드롭 가능
- 러버밴드(드래그 박스) 선택, ⌘/⇧ 클릭 다중 선택
- 컨텍스트 메뉴: 열기, Finder에서 보기, 터미널에서 열기, 경로 복사, 속성(폴더 크기 계산 포함)
- 더블클릭으로 파일은 기본 앱으로 열기

**키보드 단축키**

| 키 | 동작 |
|---|---|
| ↵ | 열기 |
| ⌫ | 상위 폴더 |
| ⌘[ / ⌘] | 뒤로 / 앞으로 |
| ⌘↑ | 상위 폴더 |
| ⌘C / ⌘X / ⌘V | 복사 / 잘라내기 / 붙여넣기 |
| ⌘A | 전체 선택 |
| ⌘⌫, Delete | 휴지통으로 이동 |
| F2 | 이름 바꾸기 |
| F5, ⌘R | 새로 고침 |
| ⇧⌘N | 새 폴더 |
| ⇧⌘. | 숨김 파일 표시 토글 |
| ⌘F | 검색 |
| Space | 미리 보기 창 토글 |
| 방향키, Home/End | 항목 이동 (⇧로 범위 선택) |
| 문자 입력 | 해당 이름으로 점프 — 같은 글자 반복 시 그 글자로 시작하는 항목 순환 (Windows 탐색기 방식) |

```
public/app.js      # 탐색기 로직 전부
```
